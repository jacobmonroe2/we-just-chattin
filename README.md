# We Just Chattin

Website for **We Just Chattin**. A single-page static site: plain HTML and CSS, no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

Hosted with GitHub Pages from the `main` branch. Push to `main` and the site updates.

## Structure

- `index.html` — page content
- `styles.css` — styling (light and dark mode)
